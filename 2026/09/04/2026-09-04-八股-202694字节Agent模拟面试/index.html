2026-09-04 字节跳动 Agent/AI 应用 日常实习 模拟面试复盘

模拟范围:字节一面(技术面)风格,题池依据真实面经(豆包大模型 AI 应用开发 2 轮技术面):项目深挖(RAG/Embedding/召回评估)+ 八股(Transformer/LoRA/交叉熵)+ 手撕(LRU/MHA)+ 情景题(幻觉/工具失败兜底)+ A/B 测试。
结构:Agent 基础与情景 → RAG → 大模型基础 → 评估与 A/B → 手撕(降难度版)→ 开放设计。项目深挖跳过(简历未完成)。

Q1 Function Calling 全流程 ✅

我的答案:用户消息带 function 说明(name/description/input/output)→ 模型判断调什么工具什么参数,输出 JSON → 客户端解析执行 → 结果返回模型。

点评:核心机制(模型不执行,客户端执行)✅。追问”结果回传后呢”答对:模型判断还需不需要继续调工具,不需要就总结回答。
修正:”关键机制是 ReAct” ❌——ReAct 是提示词范式(Thought→Action→Observation 文本),Function Calling 是 API 原生工具调用。loop 靠 stop_reason == "tool_use" 判断继续/退出。

Q1-追问:工具执行失败怎么兜底(字节二面原题) ✅
我的三条:①参数问题→错误结果+提醒回传模型 ②调用混乱→每个 function 写清边界 ③执行不停→设超时。
点评:三条都在点上。补:错误信息要可操作(“missing required field city“ 而非堆栈);设重试上限(同工具连败 3 次终止/降级)——与轮次上限/重复检测同属三道防线。

Q2 幻觉 ⚠️(温度 0 二连坑,必背)

我的答案:概率模型只说概率大的答案;手段:提示词约束/并行多跑几轮/RAG/温度 0。

点评:

  • 原因只答出 1/3。标准三条:①概率模型目标是”像”不是”真” ②没有”我不知道”机制,SFT 教出有问必答 ③训练数据过时/噪声/长尾不足
  • 温度 0 ❌——9/2 踩过又踩。温度 0 只消随机性,贪心解码照样编,幻觉根源是”没有事实依据”不是”随机性”
  • 并行多跑 ⚠️ 学名 self-consistency,提高一致性≠提高事实性
  • 自检技巧:温度 0 和并行采样互相矛盾,一起端出来会被打

必背四条手段:①RAG ②Prompt 三件套(允许说不知道/仅据给定资料/引用来源)③事后校验(另一模型做 faithfulness 检查)④对齐(RLHF 校准拒答)。
套路:**原因”机制+训练+知识边界”,手段”RAG/prompt/校验/对齐”**。

Q3 RAG 召不回排查 ✅✅(高光)

我的答案:query 和 answer 不匹配要增强 query;排查看 chunk 内容、拿什么当 query、是排序低还是压根不在 top-k 里;加 BM25 路互补。

点评:“区分不在 top-k vs 排序低”是生产级排查思维(召回问题 vs 排序问题,修法完全不同)——三场以来最好的工程直觉。BM25 互补(语义 vs 关键词/专有名词)✅。

HyDE 第三次掰正(先弄懂再答的暂停讲解):

  • Query 改写 = 把问题说得更清楚(同义词/口语转书面),改完还是问句
  • HyDE = 让 LLM 编一段假设性答案文档拿去检索——假答案的词汇句式和真文档同类,embedding 落在”文档区”,离真 chunk 近;数字编错没关系
  • 记忆锚点:改写 = 把问题说清楚;HyDE = 把答案编出来拿去搜
  • 失败模式:改写改完还不匹配;HyDE 冷门问题编跑题带偏检索
  • 实战:多路召回里原始 query/改写/HyDE 各一路,RRF 合并;话术”先分析 badcase 判断失败类型,改写解决不了再上 HyDE”

Q3-追问:Embedding 模型选型 ⚠️
✅ 语言支持(纯中文/英文/双语)。❌ “bge 会生成稀疏向量”不精确——是 BGE-M3 单型号支持稠密+稀疏+多向量三种表示,bge-large 等纯稠密。面试精确到型号。
补全因素:语言/维度与成本权衡/C-MTEB 榜单参考/长文本 max tokens/query-document 不对称处理/部署方式。
验证方法(现学):”榜单初筛(C-MTEB),自建评测集终筛(人工标注 query→正确文档,算 Recall@k/MRR),最后端到端验证”——豆包面经原题就是”召回率如何评估”。

Q4 大模型基础 ⚠️

Q4-1 交叉熵 vs MSE:只答”分类用 CE 回归用 MSE”。深度版:LLM 输出词表上的概率分布,本质是超大分类→CE;MSE 配 softmax 梯度消失,且 token 间无数值距离(错”狗”和错”飞机”一样错)。
一句话版:”LLM 是词表上的超大分类,CE 直接匹配概率分布;MSE 给连续值回归设计,配 softmax 梯度会消失。”

Q4-2 LoRA:低秩✅,但”只调整部分小窗口”❌(窗口是 Flash Attention 概念,串了)。
正确版:”冻结原权重 W,旁路加两个小矩阵 A(d×r)、B(r×d),前向 = W·x + B·A·x;可训练参数从 d×d 降到 2×d×r;推理时 B·A 可合并回 W 零延迟;多任务换 LoRA 权重底座共享。”
记忆锚点:LoRA = 冻结原文,旁边开小抄。

Q5 评估与 A/B ⚠️(字节灵魂题,题眼没答出)

我的答案:新旧 prompt 跑同任务对比,看端到端/过程/成本延迟;上线后看用户反馈,离线有偏差。

点评:离线评测部分✅(标准说法:同一评测集新旧各跑)。但在线 A/B 完全没提——这是题眼:

  • 随机分流(两组用户无系统差异)→ 跑 1-2 周比业务指标(任务完成率/点赞点踩/留存/人工转接率)→ 显著性检验(p<0.05) 字节必追
  • 话术:”离线回归当门禁 → 线上 A/B 小流量放量 → 显著才全量”

离线好≠在线好(三条):①分布 gap(评测集人工挑的,长尾覆盖不到)②指标≠体验(延迟/语气/格式在线才感知)③用户是活的(上线后行为会变)。
在线要做的:A/B + 反馈埋点 + 成功率监控 + badcase 回流评测集(持续迭代)。

Q6 手撕 ✅✅(超预期)

Q6a LRU Cache:用户力扣真实现通过。数据结构:哈希表(O(1) 找到)+ 双向链表(O(1) 排队,头最新尾最旧);必追点:为什么双向——摘中间节点要 O(1) 必须知道前驱。记忆锚点:**哈希表管”找到”,双向链表管”排队”**。
结论:用户自我评估”只懂思路不能写码”偏低,缺的是练不是能力。

Q6b Agent loop 白板(降难度版):

  • 退出条件✅(判断 stop_reason,精确版 stop_reason != "tool_use" 退出)
  • 回传+为什么再调✅(append 到 messages;补充:工具结果只是历史里一条消息,模型不会自动响应,必须再发 API 请求才继续生成——loop 的本质是每次模型发言都是一次新 API 调用)
  • 防死循环 ⚠️ “两个标记位”含糊→标准:轮次上限(max_turns=25)+ 重复检测(同工具同参连续 3 次)
  • 白板参考答案已存档于复盘(伪代码 15 行:for max_turns → create → stop_reason 判断 → 客户端执行 → assistant block + tool_result 回传 → 超限降级)

Q7 开放设计:AI 简历优化助手 ⚠️

我的答案:word/pdf 解析成 markdown(OCR 版面分析+AI 转化更好);按 JD 优化输出建议;评估=另建一个 AI 拿 jd+简历来评。

点评:OCR/版面分析✅ 真实痛点,亮点。LLM-as-a-judge✅ 但评估只答 1/4。
架构补全:解析层→**分析层(简历×JD 对齐:技能匹配/关键词缺口——用户跳过了这步)**→生成层(逐段改写+引用原文防编造)→工程项(PII 脱敏,主动提加分)。
评估补全:规则指标(JD 关键词覆盖率前后对比)/judge(带 rubric:相关性/具体性/真实性——不能编造经历)/人工金标/**采纳率闭环(建议被接受比例,北极星)**。
价值:9/2 的”评什么/怎么评/何时评”框架成功迁移到新场景——这正是面试官考的框架迁移能力。

三场规律

  1. 最大短板:术语精确性——模式更具体了:不是不知道,是版本不精确(ReAct≈FC、bge≈BGE-M3、LoRA”小窗口”)。这种错比空白危险,面试官会以为你真懂错的东西
  2. 排查/工程直觉真强:top-k vs 排序、工具失败三条、LRU 真跑通——动手过的扎实(三场一致)
  3. 温度 0 二连坑的教训:9/2 待办只背了清单没过”为什么”——温度 0 消随机性,幻觉根源是没事实依据,消随机性治不了

待办(9/4 更新,合并旧)

  • 幻觉四条手段真背下来(温度 0 已二连坑):RAG / prompt 三件套 / 事后校验 faithfulness / 对齐拒答
  • A/B 完整链路:随机分流→业务指标→显著性;离线≠在线三条(分布 gap/指标≠体验/用户是活的)
  • HyDE vs 改写锚点(第三次,应最后一次):改写=把问题说清楚;HyDE=把答案编出来搜
  • ReAct vs FC:提示词范式 vs API 原生;loop 靠 stop_reason==”tool_use”
  • 交叉熵一句话版;LoRA 一句话版(冻结+低秩旁路+可合并)
  • BGE-M3=稠密+稀疏+多向量(精确到型号)
  • Embedding 选型话术:榜单初筛/自建评测集 Recall@k 终筛/端到端验证
  • 开放设计模板:不跳步(解析→分析→生成);评估=规则+judge+人工+采纳率闭环
  • **简历(最高优先级)**——真实面试项目深挖 30 分钟起
  • (延续)Anthropic《Building effective agents》《How we built our multi-agent research system》;Q14 归因表

  • LRU 力扣真跑通——缺的是练不是能力
