面向对象

面向对象是一种编程范式，它将现实世界中的事物抽象为对象，对象具有属性（称为字段或属性）和行为（称为方法）。面向对象编程的设计思想是以对象为中心，通过对象之间的交互来完成程序的功能，具有灵活性和可扩展性，通过封装和继承可以更好地应对需求变化。

构造器

无参构造、有参构造。

this关键字

this是一个变量，可以在方法中拿到当前对象。

封装的设计要求

合理隐藏、合理暴露

javabean=实体类

  • 要求1：全部成员都是私有且提供get/setter方法
  • 要求2：类中需要提供一个无参数构造器 有参数构造器可选

实体类基本作用：可以创建对象，封装数据。

应用场景？

实体类只负责数据的存取，数据的业务交给其他类的对象处理和完成，实现数据和数据业务分离。

Static

static修饰成员变量

静态变量（类的变量）被类的全部对象共享

实例变量（对象变量）

静态变量可以用类名直接访问（推荐）

都可以拿对象.变量

static修饰方法

静态方法 属于类

实例方法 属于对象

节约内存

如果方法只是为了做一个功能而不直接访问对象的数据，定义为静态方法

如果方法需要访问对象的数据，必须定义了实例方法

（涉及实例数据用实例方法）

同一个类中类名可以省略

静态方法做工具类

工具类：方法都是静态方法

工具类没有创建对象的需求，所以构造器私有化

static注意事项

  1. 静态方法中可以直接访问静态成员，不可以访问实例成员
  2. 实例方法中可以直接访问静态成员，也可以访问实例成员
  3. 实例方法中可以出现this关键字，静态方法中不能出现this关键字
