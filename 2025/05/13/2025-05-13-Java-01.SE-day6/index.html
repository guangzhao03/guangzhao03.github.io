# day6 继承和多态 ## 继承和多态 继承非私有的方法和成员变量 public class a extends b{ } ## 权限修饰符 ![image-20250512181705771](/img/posts/2025-05-13-Java-01.SE-day6-image-20250512181705771.png) ## java继承特性 java只能单继承和多重继承 所有java类默认继承object类 ## 方法重写 声明不变，重新实现。 @override //方法重写的标志注解 要求方法名称和形参列表必须与被重写方法一致，否则报错 安全可读性好 - 子类重写父类方法时，访问权限必须大于或等于父类该方法的权限 - 重写的方法返回值类型，必须与被重写方法的返回值类型一样，或者范围更小 - 私有方法、静态方法不能被重写，如果重写会报错 Student s=new Student(); 默认 System.out.println(s) s.toString(); ## 子类构造器 - 子类的全部构造器，必须先调用父类的构造器，再执行自己。（不管则默认无参构造器，如果要构造有参构造器可以用super关键字） ## This调用兄弟构造器 借兄弟构造器 实现默认赋值 super（...）和this （...）必须在第一行且两者不能同时出现 this调用兄弟构造器 第一行会是super（...）不然会导致重复调用父类构造器 ## 多态 多态是继承/实现情况下的一种现象，表现为：对象多态、行为多态。 对象多态 ：父类的变量指向子类对象 Animal a1=new Wolf(); a1.run(); 编译看左，运行看右 Animal a2=new Tortoise() a2.run(); --- //成员变量不多态。 ### 多态好处和问题 #### 多态的好处 - 在多态形式下，右边对象是解耦合的，更便于扩展和维护 - 定义方法时，使用父类类型的形参，可以接收一切子类对象，扩展性更强、更便利。 #### 多态的问题 - 无法调用子类独有的方法 ### 多态下的类型转换 解决多态的问题，无法调用子类独有的方法 自动类型转化 父类 变量名=new 子类（）； 强制类型转化 子类 变量名=（子类）父类变量； 强转类型如果有问题，则会报类型转换异常 ClassCastException的错误 instanceof 关键字判断当前对象的真实类型 (a1 instanceof Wolf) > 对象 instanceof 类型 ## lombok技术 可以自动加get/set toString 无参构造器 导入 import lombok.Data @Data 需要开注解开关 Annotation @AllArgsConstruction 有参构造器 @NoArgsConstructor
