# day2 JavaScript js负责网页的行为 - JavaScript（简称js）是一门跨平台，面向对象的脚本语言，是用来控制网页行为，实现页面的交互效果。 - 组成： - ECMAScript：规定了js基础语法核心知识，包括变量、数据类型、流程控制、函数、对象等。 - BOM:浏览器对象模型，用于操作浏览器本身，如：页面弹窗、地址栏操作、关闭窗口等。 - DOM：文档对象模型，用于操作html文档，如：改变标签内的内容、改变标签内字体样式等。 JavaScript和Java是完全不同的语言，不论是概念还是设计，但是基础语法类似。 ECMA国际，制定了标准化的脚本程序设计语言ECMAScript，这种语言得到广泛应用。而JavaScript是遵守ECMAScript的标准的。 - JS核心语法 - JS事件监听 ## JS核心语法 ### 引入方式 - 内部脚本：将JS代码定义在HTML页面中 - JavaScript代码必须位于中 - 在HTML文档中，可以在任何地方放置任意的script标签 - 一般会把脚本置于body元素的底部，可改善显示速度 - 外部脚本： - 将JS代码定义在外部JS文件中，然后引入HTML页面中 ### 基础语法 #### 变量&常量 - JS中用let关键字来声明变量（弱类型语言，变量可以存放不同类型的值） - 变量名需遵循如下规则： - 只能用数字、字母、下划线、美元符号组成，且数字不能开头 - 变量名严格区分大小写，如name和Name是不同的变量 - 不能使用关键字，如let、var、if、for等。 - JS中用const关键字来声明常量 - 一旦声明，常量不可修改。 #### 数据类型 - JavaScript的数据类型分为：基本数据类型和引用数据类型（对象） - 基本数据类型： - number：数字（整数、小数、NAN） - boolean：布尔 - null：对象为空 typeof返回的是object - undefined：当声明的变量未初始化时 - string：字符串 反引号 单引号 双引号 - typeof获取数据类型 - 模板字符串语法： - ``反引号 - 内容拼接的时候，使用＄{} #### 函数 - 介绍：函数（funcition）是被设计用来执行特定任务的代码块，方便程序的封装复用。 - 定义：JavaScript中的函数通过function关键字进行定义，语法为： #### 匿名函数 #### 自定义对象 在箭头函数中this指向的不是当前对象，指向的是当前对象的父级 #### json - 概念JavaScript Object Notation JavaScript对象标记法 - 由于其语法简单，层次结构鲜明，现多用于作为数据载体，在网络中进行传输。 js转json JSON.stringfy() json转js JSON.parse() ### DOM - 概念 Document Object Model，文档对象模型 - 将标记语言的各个组成部分封装为对应的对象： - Document：整个文档对象 - Element：元素对象 - Atrribute：属性对象 - Text：文本对象 - Comment：注释对象 将HTML页面转化为js的对象 DOM树 - JavaScript通过DOM，就能够对HTML进行操作： - 改变HTML元素的内容 - 改变HTML元素的样式 - 对HTML DOM事件做出响应 - 添加和删除HTML元素 #### DOM操作 把页面上所有元素当作对象来处理 - 操作步骤： - 获取要操作的DOM元素对象 - 操作DOM对象的属性或方法 - 获取DOM对象 - 根据CSS选择器来获取DOM元素，获取匹配到的第一个元素：document.querySelector('选择器') - 根据CSS选择器来获取DOM元素，获取匹配到的所有元素：document.querySelectorAll('选择器') 注意：得到的是一个NodeList节点集合，是一个伪数组（有长度、有索引的数组） ### 事件监听 - 事件：HTML事件是发生在HTML元素上的“事情”。比如： - 按钮被点击 - 鼠标移动到元素 - 按下键盘按键 - 事件监听：JavaScript可以在事件触发时，就立即调用一个函数做出响应，也称为事件绑定或注册事件。 #### 语法 语法：事件源.addEventListener('事件类型'，事件触发执行的函数)； - 事件监听三要素 - 事件源：哪个dom元素触发了事件，要获取dom元素 - 事件类型：用什么方式触发，比如鼠标单击 - 事件触发执行函数：要做什么事 早期写法 （了解）：事件源.on事件=function(){...} 新语法：可以多次绑定同一事件 老语法：如果多次绑定同一事件就会覆盖事件监听触发的事件 子元素的背景色会覆盖父元素的背景色。 #### 常见事件 1、鼠标事件 click、mouseenter、mouseleave 2、键盘事件 keydown、keyup、 3、焦点事件 focus、blur 4、表单事件 input、submit #### JS模块化 如果一个js要用另一个js的函数 需要import {}from xxx 另一个js的函数需要export 模块化js script 标签里面设置 type属性为module ## Vue - Vue是一款用于**构建用户界面**的**渐进式**的JavaScript框架 构建用户界面：基于数据渲染出用于看到的界面 渐进式：可以根据开发者需求选择Vue的组件 主要分为：Vue核心包开发（局部，模块改造）、Vue核心包 Vue插件工程化开发（整站开发） ![image-20250906162621593](/img/posts/2025-09-09-Java-02.javaweb-day2-image-20250906162621593.png) - 框架：就是一套完整的项目解决方案，用于快速构建项目。 - 优点：大大提升前端项目的开发效率。 - 缺点：需要理解记忆框架的使用规则。 ### Vue快速入门 - 准备： - 引入Vue模块（官方提供） - 创建Vue程序应用实例，控制视图的元素 - 准备元素（div），被Vue控制 - 数据驱动视图 - 准备数据 - 通过插值表达式渲染页面 > 引入createApp函数从Vue中，然后调用createApp函数 形参是一个对象 createApp函数返回的调用mount方法指定div标签的某个id ‘#APP’ > 在createApp函数中调用方法的参数中要声明一种方法为data方法 这个data方法的返回值就是我们定义的数据 return返回的是对象 返回的对象内容是vue应用实例所定义的数据。 插值表达式为{{}}嵌套的两个大括号 Vue的 data一整个部分要基于后端发送的信息来特殊定制 ### 常用指令 - 指令：HTML标签上带有 v-前缀的特殊属性，不同的指令具有不同的含义，可以实现不同的功能。 | 指令 | 作用 | | --------------------- | ---------------------------------------------------- | | v-for | 列表渲染 | | v-bind | 为HTML标签捆绑属性 | | v-if/v-else-if/v-else | 条件性渲染某元素 | | v-show | 根据条件展示某元素 | | v-model | 在表单元素上创建双向数据绑定（动态获取表单值or设置） | | v-on | 为HTML标签绑定事件 | - v-for {{item}} key作为元素的唯一标识，便于vue进行列表项的正确排序复用，提升渲染性能。 插值表达式不能加入到标签内 所以有了v-bind为标签捆绑属性值 - v-bind 语法： v-bind:属性名=“属性值” 简化：:属性名=“属性值” - v-if/v-show - v-if 语法： v-if=“表达式”，表达式true显示否则隐藏 原理：基于条件判断，来控制创建或移除元素节点（条件渲染） 不频繁显示的场景 其他 v-else-if v-else - v-show 语法 v-show=“表达式” true显示否则隐藏 原来：基于CSS样式的display来控制和显示与隐藏 频繁显示的场景 - v-model 作用：在表单元素上使用，双向数据绑定。可以方便的获取或设置表单项数据 语法：v-model=“变量名” 注意：v-model中绑定的变量，必须在data中定义(createApp) - v-on 作用：为html标签绑定事件 语法： v-on:事件名="方法名" 简写为：@事件名=“...” ## Ajax 发送请求给服务端以及接收服务端发送的信息。 - 介绍：Asychronous JavaScript And XML 异步的JavaScript和XML XML：Extensible Markup Language 可扩展**标记语言**，本质是一种数据格式，可以用来存储复杂的数据结构 HTML也是标记语言 有标签 作用： - 数据交换：通过Ajax可以给服务器发送请求，并获取服务器响应的数据 - 异步交互：可以在不重新加载整个页面的情况下，与服务器交换数据并更新部分网页的技术，如：搜索联想、用户名是否可用的校验等。 ### Axios - 介绍：Axios对原生的Ajax进行封装，简化书写，快速开发。 - 官网 http://www.axios-http.cn/ - 步骤： - 引入Axios的js文件(参照官网) - 使用Axios发送情况，并获取响应结果。 ### Axios-请求方式别名 - 为了方便起见，Axios已经为所有支持的请求方法提供了别名 - 格式：axios.请求方式(url,[,data[,config]]) 注意：异步交互请求消息并不会等待。 ### async&await - 可以通过async、await可以让异步变成同步操作。async就是来声明一个异步方法，await是用来等待异步任务执行。 注意：await关键字只在async函数内有效，await关键字取代then函数，等待获取到请求成功的结果值。 ### Vue生命周期 如何做到在页面加载完毕后自动发起请求，请求服务端？ vue生命周期 - 生命周期：指一个对象从创建到销毁的过程 - 生命周期的八个阶段：每触发一个生命周期事件，会自动执行一个生命周期方法（钩子）。 beforeCreate、created、beforeMount、mounted、beforUpdate、Update、beforeUnmount、unmounted - 生命周期的八个阶段：每触发一个生命周期事件，会自动执行一个生命周期方法（钩子） 一般来说在mounted挂载阶段的时候发送请求数据
