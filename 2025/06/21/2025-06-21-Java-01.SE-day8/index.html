代码块

  • 代码块是类的五大成分之一（成员变量、构造器、方法、代码块、内部类）

代码块主要分为：静态代码块和实例代码块

静态代码块

格式：static{}

特点：类加载时自动执行，由于类只会加载一次，所以静态代码块也只会执行一次。

作用：完成类的初始化，例如：对静态变量的初始化赋值。

Arrays.toString()

打印数组的内容

实例代码块

格式：{}

特点：每次创建对象时候，执行实例代码块，并在构造器前执行。

作用：和构造器一样，都是用来完成对象的初始化，例如：对实例变量进行初始化赋值。

内部类

  • 如果一个类定义在一个类的内部，这个类就是内部类。
  • 场景：当一个类的内部，包含了一个完整的事物，且这个事物没有必要单独设计时，就可以把这个事物设计为内部类。

四种：成员内部类、静态内部类、局部内部类、匿名内部类

成员内部类

无static修饰，属于外部类的对象持有的。

Outer.Inner oi=new Outer().new Inner();

oi.show();

成员内部类访问外部类的特点（扩展）

  1. 成员内部类中可以直接访问外部类的静态成员，也可以直接访问外部类的实例成员
  2. 成员内部类的实例方法中，可以直接拿到当前寄生的外部类对象，外部类名.this

静态内部类

外部类名.内部类名 对象名=new 外部类.内部类()

Outer.Inner in=new Outer.Inner();

  1. 静态内部类中是否可以直接访问外部类的静态成员？可以
  2. 静态内部类中是否可以直接访问外部类的实例成员？不可以

局部内部类

在方法中定义的局部内部类

匿名内部类

  • 特殊的局部内部类；
  • 所谓匿名：指得程序员不需要为这个类声明名字，默认有个隐藏的名字。
  • 特点：匿名内部类本质是一个子类，并会立即创建出一个子类对象。
  • 作用：用于更方便的创建一个子类对象

匿名内部类实际上有一个名字：外部类$编号.class

内名内部类本质是子类，同时还会立即创建一个子类对象

常见使用场景

  • 通常作为一个对象参数传输给方法。
  • 需求：学生，老师要参加游泳比赛。

应用场景

  • 调用别人提供的方法实现需求时，这个方法正好可以让我们传输一个匿名内部类对象给其使用。

例如 一个button的.addActionListener() 接受的是个接口对象，我们直接用匿名内部类创建对象并重写接口的方法

开发中不是我们主动去写匿名内部类，而是我们要用别人的功能的时候，别人可以让我们写一个匿名内部类，我们才写。

函数式编程

Lambda、方法引用

此函数类似数学中的函数（强调做什么），只要输入的数据一致返回的结果也一致。

Java中的函数 （Lambda表达式）：(x)->2x+1

  • 使用Lambda函数替代某些匿名内部类对象，从而让程序代码更简洁，可读性更好。

Lambda表达式

  • JDK8开始新增的一种语法形式，他表示函数。
  • 可以用于替代某些匿名内部类对象，从而让程序更加简洁，可读性更好。

Lambda并不是可以简化全部的匿名内部类，Lambda只能简化函数接口式的匿名内部类

函数式接口：有且只有一个抽象方法的接口。

@FunctionalInterface //声明式函数式接口的注解

原理可以进行上下文推断。

Lambda表达式的省略规则

作用：进一步简化Lambda表达式

具体规则：

  • 参数类型全部可以省略不写。
  • 如果只有一个参数，参数类型省略的同时“()”也可以省略，但多个参数不能省略“()”
  • 如果Lambda表达式中只有一行代码，大括号可以不写，同时要省略分号”;”，如果这行代码式return语句，也必须去掉return.

方法引用

简化Lambda表达式

静态方法的引用，实例方法的引用，特定类型方法的引用，构造器引用。

静态方法引用

类名::静态方法

使用场景：

  • 如果某个Lambda表达式里只调用一个静态方法，并且”->“前后参数的形式一致，就可以使用静态方法引用。

实例方法引用

对象名::实例方法

使用场景

  • 如果某个Lambda表示式里只是通过对象名称调用一个实例方法，并且”->”前后参数的形式一致，就可以使用实例方法引用。

特定类型方法引用

特定类的名称::方法

使用场景

  • 如果某个Lambda表达式里只是调用一个特定类型的实例方法，并且前面参数列表中的第一个参数是作为方法的主调，后面的所有参数都是作为该实例方法的入参的，则此时就可以使用特定类型的方法引用。

构造器方法引用

类名::new

使用场景

  • 如果某个Lambda表达式里只是创建对象，并且”->”前后参数情况一致，就可以使用构造器引用。

常用API

String

  • String代表字符串，它的对象可以封装字符串数据，并提供了很多方法完成对字符串的处理。

1、创建字符串对象，封装字符串数据。

2、调用String提供操作字符串数据的方法。

String创建字符串对象的方式

方式一：

String name=”小黑”；

String name=”黑马程序员”;

方式二：

构造器 说明
public String() 创建一个空白字符串对象，不含有任何内容
public String(String original) 根据传入字符串内容，来创建字符串对象
public String(char[] chars) 根据字符串数组内容，来创建字符串对象
public String(byte[] bytes) 根据字节数组的内容，来创建字符串对象

字符串创建对象的区别。

  • 只要是以”…”方式写出的字符串对象，会存储到字符串常量池，且相同内容的字符串只存储一次。
  • 通过new方法创建的字符串对象，每new一次都会产生一个新的对象放在堆内存中。

GUI编程

Graphical User Interface

通过图形元素（窗口、按钮、文本框）与用户进行交互

与命令行相比，GUI更直观、友好。

Java的GUI编程包

  • AWT(Abstract Window Toolkit)

提供一组原生的GUI组件，依赖操作系统的本地窗口系统。

  • Swing

基于AWT,提供了更丰富的GUI组件，轻量级组件，不依赖本地窗口系统。

常用Swing组件

  • JFrame：窗口
  • JPanel：用于组织其他组件的容器
  • JButton：按钮组件
  • JTextField：输入框
  • JTable：表格

常见的布局管理器

Layout Manager可以决定组件在容器中的布局方式，避免了手动设置每个组件的位置和大小，从而简化GUI设计过程。

  • FlowLayout
  • BorderLayout
  • GridLayout
  • BoxLayout

FlowLayout：水平排列从左到右，排满换行。

BorderLayout：东南西北中

GridLayout：将容器划分成等大小的网格

BoxLayout：沿X排和沿Y排

事件处理

  • GUI编程，事件的处理是通过事件监听器(Event Listener)来完成的

常用的事件监听器对象

  • 点击事件监听器 ActionListener
  • 按键事件监听器 KeyListener
  • 鼠标行为监听器 MouseListener
  • …

给组件添加监听器对象

事件的三种写法

第一种：直接提供实现类，用于创建事件监听对象。

第二种：直接使用匿名内部类的对象，代表事件监听对象。

第三种：自定义窗口，让窗口对象实现事件接口。

第三种不仅继承窗口，也实现了事件监听接口。全部合并。
