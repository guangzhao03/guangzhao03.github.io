File、IO流

File：

  • File是java.io.包下的类，File类的对象，用于代表当前操作系统的文件（文件或文件夹）。

注意：File类只能对文件本身进行操作，不能读写文件里面存储的数据。

IO流：

  • 用于读写数据的（可以读写文件、或网络中的数据…)

File

  • File类的对象可以代表文件/文件夹，并可以调用其提供的方法对象文件进行操作。

创建File类的对象

构造器 说明
public File(String pathname) 根据文件路径创建文件对象
public File(String parent, String child) 根据父路径和子路径创建文件对象
public File(File parent, String child) 根据父路径对应的文件对象和子路径名字创建文件对象

注意：1.File对象既可以代表文件、也可以代表文件夹

​ 2.File封装的对象仅仅是一个路径名，这个路径可以存在，也允许是不存在的。

  • delete只能删除空文件夹和文件，删除后的文件不会进入文件夹
  • mkdir、mkdirs创建文件夹、createNewFile创建文件
  • list获取一级文件名称到一个字符串数组中返回
  • listFile获取当前目录下所有的“一级文件对象”到一个文件对象数组中返回

使用listFile方法时的注意事项：

  • 当主调是个文件，或者路径不存在时，返回null
  • 当主调是空文件夹时，返回一个数组长度为0的数组
  • 当主调是一个有内容的文件夹时，将里面所有的一级文件和文件夹的路径放在File数组中返回。
  • 当主调是一个文件夹时，且里面有隐藏文件，将里面所有文件和文件夹的路径放在File数组中，包括隐藏文件
  • 当主调是一个文件夹，但是没有权限访问该文件夹时，返回null

常见字符集

ASCII： 一个字节存储，第一位都是0 有效数位7位 表示128个字符

GBK: 两个字节存储，包含2万多个汉字等字符，兼容ASCII：汉字的第一个字节的第一位必须是1

Unicode： UTF-32 4个字节一个字符。 UTF-8（常用）

UTF-8：

  • 是Unicode字符集的一种编码方案，采取可变长编码方案，共分为四个长度区：1个字节、2个字节、3个字节、4个字节
  • 英文字符、数字等只占用1个字节（兼容标准ASCII），汉字字符占用三个字节

使用程序对字符进行编码和解码操作

本质：字节数组转换字符串

编码：getBytes

解码：String

IO流

I指Input，称为输入流：负责把数据读到内存中去

O指Output，称为输出流，负责写数据出去

流的方向分为：输入流、输出流

流的内容：字节流、字符流

  • 字节流：适合操作所有类型的文件
  • 字符流：只适合操作纯文本文件

IO：字节输入流、字节输出流、字符输入流、字符输出流

抽象类InputStream、OutputStream、Reader、Writer

实现类：FileInputStream、FileOutputStream、FileReader、FileWriter

字符流：16字符2字节为单位独写数据。

字节流：8位1字节位单位独写数据。

1、使用字节流读取中文，如何保证输出不乱码，怎么解决？

IO中途可能会出现异常情况，导致IO流关闭异常，因此需要主动资源释放

  • try-catch-finally
  • JDK7开始 try-with-resource

try(定义资源1、定义资源2…){}

catch(异常类名 变量名){}

try（）里面只放资源

不同编码读取乱码问题

当你的代码是UTF-8 读取的文件是GBK 解决这个乱码问题

  • 解决思路:先获取文件的原始字节流，再将其按照真实的字符集编码转成字符输入流，这样字符输入流中的字符就不乱码了
