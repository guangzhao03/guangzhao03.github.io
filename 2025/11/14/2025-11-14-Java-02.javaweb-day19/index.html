# day19 Web项目部署到服务器 Linux、Docker 桌面操作系统、移动设备操作系统、服务器操作系统。 Linux系统分为内核版和发行版 - 内核版 - 由linux核心团队开发、维护 - 免费、开源 - 负责控制硬件 - 发行版 - 基于linux内核版进行扩展 - 由各个linux厂商开发、维护 - 有收费版本和免费版本 远程连接：SSH Secure shell 安全外壳协议：putty、SecurCRT、Xshell、FinalShell ## Linux常见命令 mkdir -p 创建多级目录 rm -r 递归删除 -f强制删除 cat -n由1开始对所有输出的行数编号 显示文件内容 more 以分页形式查看文件内容 回车下滚一行 空格下滚一页 b返回上一屏 q或者ctrl+c 退出more head -n 查看文件头部内容 默认十行 tail -n 查看文件尾部内容 -f动态读取文件尾部内容并显示。 cp -r source dest 递归复制 目录的话也得加 mv source dest 为文件移动或者重命名 第二个是目录则会执行移动其他重命名 tar -zcxvf filename files 文本编辑 vim find dirName -option filename查找文件 grep -inAB word fileName从指定文件中查询指定文本内容 ## Linux软件安装 二进制发布包安装、rpm安装、yum安装、源码编译安装 rpm不能解决库依赖问题，yum会解决库依赖问题 mysql安装步骤需要 别的电脑进入linux的mysql需要配置防火墙 防火墙配置： 防火墙开放指定端口 无法访问ip对应端口是因为防火墙拦截 mysql和nginx都需要开放指定端口 ## 项目部署 1、将打包的静态资源上传到nginx的html目录中 2、配置nginx配置文件，在conf/nginx.conf 中配置反向代理服务器及路径重写规则 3、在nginx安装目录中，执行sbin目录下的nginx命令启动nginx服务 后端部署： 需要将idea连接的数据库改成linux服务器上连接的数据库，logback日志存放位置也要更改。 注意 windows上配置的，例如这次tlias系统的阿里云的acceskey java -jar ...jar 运行会占用前台窗口，窗口关闭服务也会关闭可以使用nohup指令，后台运行服务 nohup java -jar xxx.jar &>tlias.log & ps -ef | grep xxxx
